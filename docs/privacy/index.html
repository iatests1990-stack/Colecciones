«Colecciones» es publicada por [NOMBRE DEL PUBLICADOR]. No está afiliada a Microsoft, Google ni a ningún otro fabricante de navegadores.

Qué hace la extensión

Proporciona un panel lateral para guardar páginas web, enlaces, imágenes, fragmentos de texto y notas propias en colecciones organizadas en secciones, y para recuperarlas, ordenarlas, exportarlas e importarlas más tarde.

Datos que maneja

La extensión guarda en el almacenamiento local del navegador (chrome.storage.local) los títulos y las URL de los elementos, el texto seleccionado o escrito a mano, las miniaturas (como referencia a su URL original o como imagen local reducida), los nombres de colecciones y secciones y las preferencias de interfaz.

Esos datos solo existen en el equipo del usuario. La extensión no envía datos a ningún servidor propio ni de terceros, no usa analítica y no instala cookies de seguimiento.

Acceso a páginas web

Los permisos de host se usan únicamente para que el content script pueda leer la página, el enlace o la imagen sobre la que el usuario está actuando cuando pulsa «Guardar en Colecciones», guarda la selección o arrastra un elemento al panel. No se recopila el historial de navegación ni el contenido de páginas que el usuario no guarda explícitamente.

La importación desde Bing Saves se realiza leyendo el DOM de la página en la que el usuario ya ha iniciado sesión, previa acción expresa del usuario. No se realizan peticiones de red propias, no se leen cookies y no se modifica ningún dato de Bing Saves.

Sincronización opcional por archivo

Si el usuario la activa, la extensión escribe su estado en un archivo JSON que el propio usuario elige dentro de una carpeta de su nube preferida. El archivo lo gestiona el proveedor de nube del usuario; la extensión no tiene acceso a esa cuenta ni envía el archivo a ningún servidor.

Conservación y eliminación

Los datos se conservan en el navegador hasta que el usuario elimina las colecciones o desinstala la extensión. El usuario puede exportar en cualquier momento una copia completa en JSON desde el menú «⋯ → Exportar → JSON…».

Permisos solicitados

  • sidePanel: mostrar el panel lateral de Colecciones.
  • storage: guardar colecciones y preferencias en el equipo.
  • contextMenus: «Guardar en Colecciones» en el menú contextual.
  • commands: atajos de teclado para abrir el panel y guardar la página.
  • scripting y host <all_urls>: leer solo el contenido que el usuario decide guardar y detectar el atajo alternativo.
  • offscreen: mantener la sincronización por archivo con el panel cerrado.
  • downloads: descargar las exportaciones CSV, Markdown, HTML, XLSX y JSON.
  • unlimitedStorage: permitir colecciones con muchas miniaturas locales.
