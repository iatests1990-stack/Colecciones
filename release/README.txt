Release 1.0 — Colecciones
=========================

ZIP: colecciones-1.0.zip
SHA256: B71C3AEAF51ADB6935D1AF77359702EB25A785E70D540463C4569C488BA622CA

Contenido: solo manifest.json, background.js, sidepanel/, content/, lib/,
offscreen/ e icons/. No incluye datos personales, fixtures con colecciones
reales, historial de git ni documentacion de desarrollo.

Instalacion local (Edge, Chrome, Brave, Vivaldi, Opera):
- Doble clic en instala-colecciones.exe, o extrae instalador-colecciones.zip
  y ejecuta install.ps1. Elige navegador si tienes varios; la extension se copia
  a %LOCALAPPDATA%\Colecciones\Extension y se muestra la URL de extensiones
  del navegador (Chromium no la abre automaticamente). Activa "Modo
  desarrollador", pulsa "Cargar desempaquetada" y elige esa carpeta. Guia
  completa en docs/instalacion.md.

Antes de publicar:
1. Sube este ZIP como nueva extension (version 1.0) en Microsoft Edge Add-ons.
2. Usa los textos de docs/store/listing.md, el logo release/logo-300.png y
   las capturas de docs/store/screenshots/.
3. La politica de privacidad esta en https://iatests1990-stack.github.io/Colecciones/
